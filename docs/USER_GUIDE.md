# Lawyer Case Agent  
律师日常办案使用手册

> 面向：不懂 Python、不看代码的律师本人。  
> 不需要 Cursor，不需要命令行调试，不需要 pytest。

---

## 1. 这个系统现在能做什么

当前版本可以协助你完成一条民事起诉准备主链：

1. 创建案件  
2. 上传合同、付款凭证、催款函等材料（优先 **可复制文字的 PDF / DOCX**）  
3. 由 AI 整理证据候选  
4. 由你确认证据  
5. 由 AI 提出案件事实候选  
6. 由你确认事实与诉讼请求  
7. 由 AI 起草起诉状草稿  
8. 由你审核并批准草稿  

**重要：**

- AI 只提出建议，**律师负责最终确认**。  
- 生成的是**律师审核草稿**，不是法院自动提交文件。  
- 当前**没有** Word/PDF 导出、电子签名、法院提交、法律检索库、登录多用户。

**当前版本已知阻塞（请先读）：**

> 案件分析后，系统**不会自动生成当事人候选**；浏览器也**没有“新增当事人”入口**。  
> 因此，在「确认当事人」这一步，普通律师本人目前**无法独立走完全程**到起诉状批准。  
> 详见第 13 节。证据确认、事实确认、诉讼请求与起诉状能力本身已可用，但当事人录入能力缺失会挡住完整闭环。

## 2. 第一次使用前准备

### 2.1 你需要准备什么

| 项目 | 要求 |
| --- | --- |
| 电脑 | Windows 11（本机已验证） |
| Python | 3.12（项目要求 ≥ 3.11） |
| 数据库 | 本机 PostgreSQL 服务（已验证：`postgresql-x64-17`） |
| 浏览器 | Chrome / Edge 等均可 |
| 网络 | 使用真实 AI 时需可访问 DeepSeek |
| API Key | DeepSeek API Key（放入 `.env`，不要发给他人） |

**不需要：** Redis、Celery、Node.js、npm。

### 2.2 首次安装（只需做一次）

用 PowerShell：

```powershell
cd "C:\Users\37108\Desktop\律师助理"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env
```

然后用记事本打开 `.env`，至少确认：

```text
DATABASE_URL=postgresql+psycopg://litigation_agent:litigation_agent_dev@127.0.0.1:5432/litigation_case_agent

LLM_MODE=real
LLM_PROVIDER=openai_compatible
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=你的新DeepSeek_API_Key
LLM_MODEL=deepseek-chat
LLM_TIMEOUT_SECONDS=60
LLM_MAX_RETRIES=2
```

> 请使用**新的** DeepSeek Key。不要把 Key 写进手册、聊天记录或发给他人。

初始化数据库结构（首次，或升级后按开发说明执行）：

```powershell
alembic upgrade head
```

确认 PostgreSQL 服务正在运行（Windows「服务」里查看 `postgresql-x64-17`）。

## 3. 每天怎么启动

最短路径见 [QUICK_START.md](QUICK_START.md)。

日常命令：

```powershell
cd "C:\Users\37108\Desktop\律师助理"
.\.venv\Scripts\Activate.ps1
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

或双击：

```text

```

保持该黑色窗口开着，不要关。

浏览器打开：

```text
http://127.0.0.1:8000
```

系统会进入案件列表页。

## 4. 怎么创建案件

1. 打开 `http://127.0.0.1:8000`  
2. 进入「案件列表」  
3. 点击「新建案件」  
4. 填写案件名称，例如：`使用手册验收-设计优化咨询费纠纷`  
5. 创建后进入案件工作台  

---

## 5. 怎么上传材料

在案件工作台的「材料」区域选择文件上传。

推荐材料（示例，位于项目内合成样例目录，**勿用真实客户材料做测试**）：

```text
backend\tests\fixtures\synthetic_zh\01_设计优化咨询合同.docx
backend\tests\fixtures\synthetic_zh\02_付款凭证.docx
backend\tests\fixtures\synthetic_zh\03_服务成果及验收说明.docx
backend\tests\fixtures\synthetic_zh\04_催款函.docx
```

上传后，材料状态应显示解析成功（`SUCCEEDED`）。

**当前建议：**

- 优先上传**可复制文字**的 PDF / DOCX  
- **纯扫描件 PDF** 暂不建议作为主要输入（OCR 未可靠可用）  

若显示 `FAILED`：检查文件是否损坏或格式不对，然后重新上传。

## 6. 怎么开始 Agent

在对话框输入：

```text
开始处理这个案件
```

正常结果：工作流已启动，系统开始处理。

不知道做到哪一步时，问：

```text
现在做到哪了？
```

页面左侧工作流状态应与 Agent 回复一致。

## 7. N0–N9 办案流程（人话版）

| 步骤 | 含义 | 谁做 |
| --- | --- | --- |
| N0 创建案件 | 建案 | 你 |
| N1 解析材料 | 抽取文字 | 系统 |
| N2 AI 整理证据 | 提出证据候选 | AI |
| **N3 律师确认材料** | 接受/排除证据 | **你决定** |
| N4 AI 分析案件 | 提出事实候选 | AI |
| **N5 律师确认当事人** | 确认原告/被告 | **你决定（当前受阻，见第13节）** |
| **N6 律师确认案件事实** | 确认/拒绝事实 | **你决定** |
| **N7 律师确认诉讼请求** | 确认请求金额与方向 | **你决定** |
| N8 AI 起草起诉状 | 生成草稿 | AI |
| **N9 律师审核起诉状** | 批准草稿 | **你决定** |

推进下一步，通常说：

```text
继续
```

但在确认门上，**「继续」不会替你自动确认**。

必须说清楚对象，例如「确认事实1」「批准这份起诉状」。

## 9. 怎么暂停和第二天继续

当天说：

```text
暂停
```

然后可以关闭浏览器。服务窗口若也关闭，第二天按第 3 节重新启动服务。

再次打开：

```text
http://127.0.0.1:8000
```

进入同一案件，输入：

```text
恢复
```

案件、进度、对话与草稿均保存在数据库中，不是仅存在内存里。

## 10. 怎么查看起诉状

输入：

```text
查看起诉状
```

或在工作台草稿区域点击查看。

请人工核对：

- 原告 / 被告名称  
- 诉讼请求金额（例如 700,000 元）  
- 事实与理由是否来自已确认事实  
- 证据目录  
- 「待律师补充」字段（住所地、法院等）  

---

## 11. 怎么批准案件成果

1. 先输入 `好` —— 应**不会**批准  
2. 明确输入：`批准这份起诉状`  
3. 再输入：`继续`  
4. 工作流状态应为 **成功结束（SUCCEEDED）**

批准后仍只是所内草稿终态，**不是**向法院提交。

## 12. 常见问题

### AI 调用失败 / 网络失败

若提示 AI 调用失败：

1. **不要**重复确认已经确认过的业务数据  
2. 检查网络是否可访问 DeepSeek  
3. 检查 `.env` 中的 `LLM_API_KEY` 是否有效  
4. 稍后输入「继续」或「重试」（若界面提供）  

### 材料解析失败

显示 `FAILED` 时：确认文件为有效 PDF/DOCX 后重新上传。当前版本不要指望自动 OCR 修复扫描件。

### 卡在「确认当事人」

这是当前版本限制，不是你的操作错误。见下一节。

---

## 13. 当前版本限制

1. **当事人录入能力缺失（阻塞完整闭环）**  
   - AI 分析不会自动生成当事人候选  
   - 浏览器没有“新增当事人”按钮  
   - Agent 也没有“录入原告/被告”的稳定指令  
   - 因此律师本人无法仅靠浏览器走完 N5→SUCCEEDED  

2. 扫描 PDF / 中文特殊字体 PDF：解析不稳定，优先 DOCX 或可选中文字的 PDF  

3. 无 Word/PDF 导出、无法院提交、无登录权限、无法律数据库 / RAG  

4. 诉讼请求与事实之间仍有一项已登记技术债（D-022）：  
   **批准起诉状前，请人工复核金额与依据事实。**

5. 生成物是**律师审核草稿**，不是正式立案文书。

---

## 14. 怎么停止系统

1. 在启动服务的窗口按 `Ctrl + C`  
2. 关闭浏览器即可  

不要强制结束 PostgreSQL，除非你明确知道自己在做什么。
